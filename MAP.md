# PLEDGE: file map

One-line purpose per file, in load order (`src/order.txt`). Sizes are in KB, and 1 KB is about 300 tokens. Find code with `grep -n "function foo" src/js/*.js`, then read just that part with `sed -n 'A,Bp'`.

## Never open
- `src/data/ucd.js` (363 KB, one line): the campus map data. The building list is `UCD.B`.
- `src/data/uct.js` (226 KB): the terrain heightmap, read by `terrH(x,z)`.
- `src/data/music.js` (1.1 MB): the music, stored as base64 text.
- `dist/*`: generated by the build.
- `vendor/three-r128.min.js`: the THREE.js library.
- `docs/HISTORY.md` (100 KB): the full change log (V1–V211). Only grep it, for example `grep -n "V18[0-9]" docs/HISTORY.md`.
