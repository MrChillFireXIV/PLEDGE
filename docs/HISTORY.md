# PLEDGE — source map

Single-page THREE.js (r128) game. **Edit `src/`, then run `python3 build.py --check`** → produces `dist/PLEDGE.html` (single file; this is what you publish/open).
All `src/js/*.js` are concatenated **in `src/order.txt` order into ONE `<script>`** (strict mode, shared global scope, function hoisting). Do not turn them into ES modules or separate `<script>` tags, and don't reorder them.

Token guide (rough, ~3.3 bytes/token): the whole game is ≈460k tokens. Each part below is ≈10–16k. **Read MAP.md → open only the one part you need → use `grep -n` / `sed -n 'A,Bp'` for big ones.**
